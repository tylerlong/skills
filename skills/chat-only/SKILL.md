# Chat Only

Switch the agent into chat-only mode.

## Behavior while on

- While chat-only mode is on, the agent must not change the code base, except that the prohibition is temporarily lifted for a single user request when the user asks the agent to change.

## Changing the mode

- The mode turns on or off only on an explicit user request.
